# Arch Restaurant & Cafe — digital menu

    menu/index.html
    menu/menu-data.js
    menu/logo.svg

The dish photos (001.jpg … 162.jpg) stay where they are, at the repository root — nothing else changes, and https://daniyal430.github.io/arch-menu/ is untouched.
